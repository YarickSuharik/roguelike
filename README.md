# Курсовой проект: Roguelike-игра

Консольная ролевая игра (RPG) в жанре Roguelike, пошаговой механикой и элементами случайности.

## Комманды сборки
VS:
cl /EHsc /std:c++17 *.cpp /Fe:roguelike.exe

## О проекте
Проект представляет собой классический «рогалик» в текстовом (консольном) интерфейсе. 
* **Процедурная генерация:** Каждый запуск игры создает уникальный лабиринт с комнатами, коридорами, врагами и лутом.
* **Пошаговый игровой процесс:** Окружение и монстры двигаются только тогда, когда совершает действие игрок.
* **Перманентная смерть (Permadeath):** У игрока есть только одна жизнь. После смерти весь прогресс теряется, и игра начинается заново.
